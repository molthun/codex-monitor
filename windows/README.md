# CodexMonitor for Windows

Rainmeter desktop widget with a LibreHardwareMonitor bridge. Overview of all platforms: [../README.md](../README.md).

On Windows, hardware sensors come from a bundled CodexBridge executable using LibreHardwareMonitor, and Rainmeter reads a flat text file generated by that bridge.

## Current Status

- Production install root: `C:\CodexMonitor`
- Active Rainmeter skin: `<RainmeterSkinPath>\CodexMonitor\CodexMonitor.ini`
- Sensor output file: `C:\CodexMonitor\@Resources\temps.txt`
- Bridge scheduled task: `CodexMonitor Bridge Elevated`
- Display watcher: `C:\CodexMonitor\Watch-PrimaryDisplay.ps1`
- Optional local staging/reinstall kit: `<LocalStagingFolder>`
- Source of truth for collaboration: GitHub repository

## Main Features

- CPU load, CPU temperature, CPU fan RPM.
- RAM usage.
- GPU load, GPU temperature, GPU fan RPM and percent.
- Dedicated VRAM used/total and usage percent.
- Board/case/PSU fan display based on hardware sensor mapping.
- Ethernet, Wi-Fi, and Wi-Fi AP traffic split.
- Smart network panel: Download and Upload bars split into Internet (blue) and LAN (mint), scaled to the link speed with a tick at your Internet plan (`network.internetDownMbps` / `internetUpMbps`), amber when the plan is maxed out; a mirrored graph in the same colors.
- **Top processes**: which applications use the network right now, by their readable names and icons (`Yandex Browser`, `Windows file sharing (SMB)`, service display names for `svchost`, `node · Visual Studio Code` for helpers), from per-connection TCP counters. UDP/QUIC shows up as `UDP / other`.
- Update notifications: a new GitHub release shows a Windows notification with **Update now** and **Release notes** (`display.autoUpdate`: `"notify"` (default), `true` = install silently, `false` = off).
- Any number of fans (board, AIO pump, radiator — whatever LibreHardwareMonitor reports, coolers included), named and ordered as you like, each with its own "warn when it stops"; a graphics card in its 0 RPM mode shows "idle".
- Extra temperatures after CPU and GPU (liquid, board, drives) with their own amber/red thresholds.
- Graphics card of your choice: NVIDIA, AMD or Intel (VRAM for all three).
- Disk I/O and used space for up to six drives, with your own names.
- **Generated skin**: the Rainmeter skin is built from your settings — any size (automatic by screen height, 1080p / 2K / 4K, or a custom percentage), shrunk to fit the screen, only the sections you want.
- Automatic positioning on the current primary monitor; the skin is rebuilt when the screen resolution changes.
- **Tray icon**: show/hide the widget, settings, check for updates, install an update, restart the widget.
- Settings window (tray icon, Start menu, desktop shortcut) with the same sections as the Linux one: Widget, Hardware, Network, Updates.
- Updates apply without signing out: the bridge, skin, tray icon and display watcher restart with the new version.

## Required Software

- Windows 11.
- Rainmeter 4.5.x or newer.
- NVIDIA driver with `nvidia-smi.exe` available.
- The widget is display-only. Fan behavior is left to the user's BIOS/UEFI, drivers, or existing system tools.

## Configuration

The project is configured through:

```text
config.json
```

`config.json` is the local working config and is ignored by Git. On first install, it is created from the public template:

```text
config.example.json
```

Edit `config.json` directly on your workstation. Scripts pick it up on the next run; long-running services should be restarted after config changes.

To install and configure everything from scratch on a clean PC, download **`Install-CodexMonitor.cmd`**
from the [latest release](https://github.com/molthun/codex-monitor/releases/latest) and double-click it,
or run in PowerShell:

```powershell
irm https://raw.githubusercontent.com/molthun/codex-monitor/main/install.ps1 | iex
```

Both ask for administrator rights by themselves. Every release (including test pre-releases) has its
own `Install-CodexMonitor.cmd`, which installs exactly that version.

This bootstrap command will:
1. Request **Administrator** elevation.
2. Download the latest public source ZIP from GitHub to `C:\CodexMonitor`.
3. Copy the `windows` folder there and save a local version marker so future background updates can compare against GitHub.
4. Hand off execution to the main installer (`Setup-CodexMonitor.ps1`), which will:
   - Detect and install all remaining prerequisites (**Rainmeter**) using `winget`.
   - Run the graphical **Configuration Wizard** (`Configure-CodexMonitor.ps1`, backed by `CodexBridge.exe --settings`) to choose widget scaling (Auto, 1080p, 4K), choose up to three local disk rows, set network interface exclusions, and configure update behavior.
   - Copy the bundled bridge executable, configure the startup shortcut, register the elevated scheduled tasks, configure active `Rainmeter.ini` layout/coordinates, and load/activate the CodexMonitor skin.

## Daily Commands

Refresh the skin:

```powershell
& "C:\Program Files\Rainmeter\Rainmeter.exe" !Refresh "CodexMonitor"
```

Open settings:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\CodexMonitor\Deploy\Configure-CodexMonitor.ps1"
```

Rebuild the skin from `config.json` (size, sections, drives, fans) and position it:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\CodexMonitor\Deploy\Switch-WidgetSize.ps1"
```

The size itself is a setting (Settings → Widget, or `profiles.default` / `widget.scale` in the config).

Restart widget services:

```powershell
Stop-ScheduledTask -TaskName "CodexMonitor Bridge Elevated"
Start-ScheduledTask -TaskName "CodexMonitor Bridge Elevated"
& "C:\Program Files\Rainmeter\Rainmeter.exe" !Refresh "CodexMonitor"
```

## Upgrading Prerequisites

The background display watcher checks for available Rainmeter updates once every 24 hours. If an update is found, a Windows GUI prompt will appear. Clicking **Yes** will automatically perform the update safely (closing applications to prevent file locks, running `winget` silently, and restarting everything cleanly).

You can also trigger this update manually at any time by running:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\CodexMonitor\Deploy\Upgrade-Prerequisites-And-Apps.ps1"
```

## Size

The skin is generated by `CodexBridge.exe --build-skin` from the settings, so there are no fixed
presets: one layout in 1080p units (430 px wide) is scaled.

| Setting | Width |
| --- | --- |
| Automatic | by screen height: below 1400 px → 1080p, below 2000 px → 2K, otherwise 4K |
| 1080p / 2K / 4K | 430 / 540 / 720 px |
| Custom | 50–250 % of 430 px |

With "Fit to screen height" (default) the widget shrinks when it would be taller than the screen,
e.g. on a 1366×768 laptop. Hiding sections makes it shorter as well.
